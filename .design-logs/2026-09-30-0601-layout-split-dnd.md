# Layout を左右の二つの DnD 列にする

Date: 2026-09-30 06:01

## Problem

Layout は 1 件ずつ大きな Card をドラッグして並べ替える。項目が多いと移動距離が長く、同じ操作の繰り返しになる。退避用の別リストと、複数項目を一塊で動かす操作が欲しい。グループ（レイヤー）は要らない。

## Approach

- 画面を左右二等分する。既定は左が並べ替え列、右が退避列。見出し下の「左右入れ替え」は列の画面上の位置だけを入れ替える。中の項目は動かさない。
- 二つの列は同じ `type` の `dragHandleZone`。列の中は上下、列をまたいでもドロップできる。ドラッグはグリップだけ。行クリックでその列の選択を付け外しし、Shift+クリックで範囲を足す。選択中のグリップは、その列で選んだ項目を元の相対順のまま一塊で動かす。
- 二つの列は同じ `EditorComponent` 参照の分割で、セッション上の presentation 状態に置く。snapshot / IR には載せない。退避が 1 件以上のあいだは `replaceComponents` しない。0 件に戻ったときだけ並べ替え列の順を確定する。
- 退避が 1 件以上のときは Layout タブをエラー色にし、error Toast を 1 件出す。`validateUiDefinition` には足さない。自動保存の effect が退避の有無を読み、空でないあいだは current / history を書かない。空に戻ったら、止まっていた差分を同じ debounce で保存する。

## Out of scope

永続グループ。Drawer。退避順の snapshot 保存。
